Raspberry Pi 4 Flasher

Upload kernel8.img. Firmware files and config.txt are checked and fixed automatically.
Requires Chrome or Edge on desktop. Uses the File System Access API on a folder you pick — doesn't work in Safari, Firefox, mobile, or inside an embedded preview. Missing firmware files are pulled from the official raspberrypi/firmware GitHub repo over your own connection.
Before you flash — read this
  1. This only works on an SD card that already has Raspberry Pi OS imaged onto it once (via Raspberry Pi Imager / Etcher). That's what creates the system-boot + writable partitions this tool needs. It cannot partition a blank card.
  2. Your kernel8.img must be compiled for AArch64, linked with the correct entry point (RPi4 default load address is 0x80000), and converted to a raw binary — not a raw unstripped ELF.
  3. Insert the SD card into your card reader and let your OS mount it before opening this page.
  4. Have your build output ready to drag in — any filename is fine, it gets renamed to kernel8.img automatically.
If this card was previously booting full Raspberry Pi OS (Linux), flashing here removes the kernel= override in config.txt so your bare-metal image boots instead. To restore Linux boot later, you'd need to add that line back manually.

After you flash — read this
  1. Eject the SD card properly through your OS before pulling it — don't unplug it while it's still mounted.
    Linux: udisksctl unmount -b /dev/sdX1 udisksctl unmount -b /dev/sdX2 udisksctl power-off -b /dev/sdX
  2. Insert the card into the Pi 4 and power it on.
  3. If enable_uart=1 is set (the tool ensures this), connect a USB-to-serial adapter to GPIO14 (TX), GPIO15 (RX), and GND, then open a serial terminal at 115200 baud to see boot output.
  4. If it doesn't boot: double check the linker script's entry point / load address, confirm the file is a raw binary (not ELF), and confirm arm_64bit=1 is in config.txt.
config.txt is never wholesale overwritten — only the lines needed to boot kernel8.img are added or corrected, everything else you've set is left alone. Every change is logged in the console above, not applied silently.
